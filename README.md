# Kanto Sobres — pokemonIDLE

Juego de colección y combates automáticos en Kanto. Los archivos index.html, JS y CSS son la versión preparada para GitHub Pages.

source-project.zip contiene el código fuente React/TypeScript y la configuración para desarrollarlo y publicar futuras versiones.

La partida se guarda en el navegador. Puedes exportarla e importarla desde Ajustes.
